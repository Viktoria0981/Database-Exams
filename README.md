## База данных "Экзамены"
База данных для хрения информации о прошедших экзаменах, результатах, принимавших участие людях
### Структура репозитория
* **/schemas** — схемы БД
* **/data** — данные для загрузки в БД
* **/base_part** — обязательные пункты, кроме схем
* **/advanced_part** — дополнительные пункты, кроме тестов
* **/tests** —  тесты
### 1 итерация
Добавление конценптуальной, логической и физической схем
в папку schemas
### 2 итерация
Создание таблиц + заполнение, SQL запросы
